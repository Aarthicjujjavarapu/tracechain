# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: **aarthij029@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Any suggested fix (optional)

You will receive an acknowledgement within 48 hours and a resolution timeline within 5 business days.

## Scope

In scope:
- Remote code execution via SDK or backend
- Authentication/authorization bypass in the backend API
- Data exfiltration from the storage layer
- Dependency vulnerabilities with known exploits

Out of scope:
- Denial of service against self-hosted instances
- Issues requiring physical access
- Social engineering

## Disclosure policy

We follow coordinated disclosure. We will work with you to understand and fix the issue before public disclosure. Credit will be given in release notes unless you prefer anonymity.
